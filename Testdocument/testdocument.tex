\section*{Pdf-documenten van GitHub openen in een browser}

Dit pdf-document kan gebruikt worden om te kijken of het correct wordt geopend in een browser.
Pdf-documenten die op GitHub zijn opgeslagen worden namelijk standaard gedownload.
Dit komt omdat GitHub het \dquote{content-type} van pdf-documenten niet correct instelt.

De aanpassingen die nodig zijn voor de verschillende browsers om dit probleem op te lossen zijn te vinden op de volgende internetpagina:
\url{https://hrelektrotechniek.bitbucket.io/pdf/index.html}.

Door op de volgende link te klikken kun je testen of dit document op pagina 2 wordt geopend in een browser:
\url{https://github.com/HR-ELEKTRO/latex-stijl/Testdocument/testdocument.pdf#page=2}.

Door op de volgende link te klikken kun je testen of dit document op pagina 3 wordt geopend in een browser:
\url{https://github.com/HR-ELEKTRO/latex-stijl/Testdocument/testdocument.pdf#section.3}.
